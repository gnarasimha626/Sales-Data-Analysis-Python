# Sales Data Analysis Using Python

## Project Overview

This is a beginner-level Data Analytics project that analyzes a small sales dataset using Python and Pandas.

The project calculates total sales, identifies the highest-revenue products and cities, and creates summary CSV files.

## Business Questions

This project answers:

1. What are the total sales?
2. How many products were sold?
3. Which product generated the highest revenue?
4. Which city generated the highest revenue?
5. Which product category generated the most revenue?
6. How do sales change by month?

## Tools & Technologies

- Python
- Pandas
- CSV
- Basic Data Analysis

## Files

- `sales_data.csv` — original sales dataset
- `sales_analysis.py` — Python analysis script
- `product_sales_summary.csv` — sales summary by product
- `city_sales_summary.csv` — sales summary by city
- `monthly_sales_summary.csv` — sales summary by month

## How to Run

1. Install Python.
2. Install Pandas:

```bash
pip install pandas
```

3. Keep `sales_data.csv` and `sales_analysis.py` in the same folder.
4. Run:

```bash
python sales_analysis.py
```

The analysis identifies which products and cities generate the most revenue. These insights can help a business understand sales performance and focus on high-performing products and locations.
